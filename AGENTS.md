# AGENTS.md

Single-binary ARM C program: an interactive DRM/KMS text menu for the GStick 4K
Lite (Rockchip RK3032). No tests, no CI, no lint/typecheck config in the repo.

## Build / verify

- `make` — cross-compile with the Bootlin 2018.11 toolchain, then `strip` and
  print the max required `GLIBC_*` symbol. There is no other verification step.
- `make install` — copy binary + `share/fondo-menu-1080.png` into `$(ROOTFS)`.
- `make clean`.
- The build needs a workspace holding `toolchain/`, `ra_source/`,
  `work-rootfs-test/`. It no longer assumes the repo lives inside it: set
  `DTC_WORKSPACE` (currently exported in `~/.bashrc` as
  `/home/neonatox/sources/ROCKCHIP`); if unset, the legacy layout (repo one level
  below the workspace) is assumed. These siblings live **outside** the repo and
  are not checked in, so a bare clone cannot build. Do not invent paths — ask
  where the workspace is. Individual overrides: `CROSS_COMPILE`, `SYSROOT`,
  `ROOTFS`, `LIBDRM_SRC`, `LIBDRM_LIB`.
- Deployment is separate: `./sysroot-install/install-sysroot.sh` stages the
  binary, swaps libdrm and installs `S99testshell`; packaging (`mksquashfs`) and
  flashing (`dd` to rootfs p4) are manual, outside this repo.

## Source layout

- `src/drm-text-console.c` — the entire program (single ~1.9k-line file).
- `src/fuente-intv.h` — 8x8 "Intellivision" font; defines `FONT_W`/`FONT_H` and
  `font_data[]`. Included by the C file.

## Critical gotchas

- **Do not run `src/generate.py`.** It is an obsolete generator that would
  overwrite `src/drm-text-console.c` with a stale version. It refuses unless
  `--force` is passed, but never pass it. Likewise `fuente-intv.h` claims to be
  generated by `herramientas/generar_fuente_intv.py`, which no longer exists —
  treat both files as hand-maintained sources.
- **`README.md` and `docs/DRM_TEXT_CONSOLE.md` describe an older design and are
  stale.** Trust the code: the mode is chosen dynamically (nearest to 60 Hz,
  often 1920x1080 — not fixed 1280x720), the font is 8x8 (not VGA 8x16), and the
  menu is 9 items with no "System Info" and a real VT shell (not an embedded
  shell). Update docs only if asked; verify against source first.
- **libdrm ABI trap:** the factory rootfs `libdrm.so.2` requires `GLIBC_2.29` and
  the binary won't load. The test rootfs must use
  `ra_source/ra/libdrm/build2018/libdrm.so.2.134.0` (SONAME `libdrm.so.2`).
  `install-sysroot.sh` handles this; `INSTALL_DRM_HEADERS=1` also copies DRM
  headers into the toolchain sysroot.
- Framebuffer format is auto-negotiated at runtime (XRGB8888 → RGB565 →
  ARGB8888 → RGB888, then legacy `drmModeAddFB`). Keep `put_pixel`/`blit_565`
  bpp-aware (16 vs 32) when touching drawing code.

## Runtime conventions

- Persistent debug log: first writable of `/mnt/sdcard/dtcon.log`,
  `/sdcard/dtcon.log`, `/data/dtcon.log`. `/mnt/sdcard` is the real exFAT p5; do
  not assume `/sdcard` exists.
- Input is evdev: opens every keyboard/gamepad `/dev/input/event*` and rescans
  every 2 s; mapped to internal `VK_*` codes in `map_key()`.
- Game menu config: `/mnt/sdcard/drm-text-console.cfg` (lines
  `Name | core.so | rom` or `Name | /cmd args`, optional 4th `thumb` field).
  Thumbs: `/mnt/sdcard/thumbs/<sys>.png` (`core_sys_map[]` maps core→sys).
- Background PNG lookup: `/mnt/sdcard/thumbs/fondo.png`, `/mnt/sdcard/fondo.png`,
  then `/usr/share/drm-text-console/fondo.png`.
- The "Shell" entry drops DRM master and hands `/dev/tty1` (fbcon) to `/bin/sh`.
